Locating hydraulic-fracture microseismicity with time-reverse imaging

Simulate microseismic events along a hydraulic fracture in a layered shale-play model, record them on monitoring arrays, and locate them by back-propagating the time-reversed recordings with the 2D acoustic wave equation. Compare locations made with the correct velocity model against a wrong one. Python and NumPy run in your browser.

About the method

The solver advances ptt + 2σpt = v(x,z)²∇²p + s with second-order time stepping and an eighth-order spatial stencil (course notes, Module 06). A 45-node quadratic sponge outside the model absorbs outgoing waves.

All events are simulated in one forward run (superposition). For imaging, the recordings are reversed in time and injected at the receivers. Because origin times are unknown, events are picked as local maxima of p² in space and reverse time; a focus at reverse time τ implies an origin time T − τ − 1.5/f. A one-wavelength mute around each receiver removes the injection points from the image.

Limitations: 2D acoustic (P-wave only) physics, line-source geometry, no source mechanisms, and roughly half-wavelength resolution. A single vertical well cannot tell which side of the well an event lies on (mirror ambiguity).
